# Agent memory entry

Entry point for durable project memory about KeyMux.

* [`STATUS.md`](STATUS.md) - what exists, what was verified, what is open.
* [`EXPERIENCE.md`](EXPERIENCE.md) - reusable, verified facts about this
  machine's Clash Verge Rev / Mihomo setup and about KeyMux itself.

Rules used here: an entry is only reused when it was verified (a measurement, a
reproducible command, or a quoted source). Anything unverified is marked as an
assumption and must be re-checked before it is acted upon.
